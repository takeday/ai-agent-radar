- Notion MCP サーバー (`mcp.notion.com/mcp`) に Claude Managed Agents からリモート MCP として接続する際に同じ問題が発生しています。エラー: tools.47.custom.input_schema: input_schema は oneOf、allOf、または...をサポートしていません — kano-sakuma (3 votes) — https://github.com/makenotion/notion-mcp-server/issues/340

- 特定できました。27 個のツール中ちょうど 1 つが影響を受けます: `notion-create-attachment`。その `inputSchema` は、トップレベルの `anyOf` で3つのブランチ（inline `content`、`source_url`、`source_file_id`）を持ち、トップレベルの `properties` がありません — TomasEkeli (1 votes) — https://github.com/makenotion/notion-mcp-server/issues/340

- 同じ問題に遭遇し、このスレッドを見つけました — 私たちの方でも同じ動作が確認できます。Notion MCP コネクタを有効にするとセッション全体が壊れ、問題のあるスキーマを持つ特定のツールだけではなく、全体が影響を受けます — ikasumiwt (0 votes) — https://github.com/makenotion/notion-mcp-server/issues/340
